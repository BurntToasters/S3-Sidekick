      Check for updates now

      Performance

      Safe uses less memory and runs slower. Balanced suits most transfers. Max gives the highest throughput, using more memory and CPU. Custom appears once an Advanced value no longer matches the preset.

      Behavior

      Some providers cannot enforce create-only writes, so another client could create the same key before a transfer finishes. When on, S3 Sidekick asks before writing to those providers.

      OS notifications for finished transfers and updates stop when this is off; in-app toasts still appear; the operating system can also block them.
