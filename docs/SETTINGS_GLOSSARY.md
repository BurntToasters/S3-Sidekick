# Settings Glossary

| Setting                                      | Meaning                                                                                                                                                                                                                                      |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Update channel                               | `Stable` follows published releases. `Beta` follows pre-release builds and also includes newer stable releases.                                                                                                                              |
| Automatically check for and download updates | Checks for new versions in the background and downloads them. Installing still needs your confirmation.                                                                                                                                      |
| Transfer performance                         | `Safe` lowers memory and concurrency; `Balanced` is the default; `Max` favors throughput. `Custom` is shown, not chosen, once an Advanced value no longer matches the preset; choosing `Safe`, `Balanced` or `Max` applies its values again. |
| Bandwidth limit                              | Maximum aggregate transfer rate. Blank or unlimited uses available bandwidth.                                                                                                                                                                |
| Desktop notifications                        | OS notifications for finished transfers and updates. Off stops them; in-app toasts still appear.                                                                                                                                             |
| Retry delay                                  | Initial wait after a retryable failure. Later waits grow exponentially.                                                                                                                                                                      |
| Parallel download threshold                  | Files at or above this size use range requests; smaller files use one request.                                                                                                                                                               |
| Download part size                           | Bytes in each parallel range. Larger parts use more memory and fewer requests.                                                                                                                                                               |
| Download concurrency                         | Number of ranges downloaded simultaneously for one file.                                                                                                                                                                                     |
| Upload part size                             | Bytes in each multipart upload part. Larger parts use more memory and fewer requests.                                                                                                                                                        |
| Upload concurrency                           | Number of multipart upload parts sent simultaneously.                                                                                                                                                                                        |
| Resume transfers                             | Stores encrypted checkpoint state for large interrupted downloads.                                                                                                                                                                           |
| Checksum verification                        | Compares server-provided integrity checksums after transfers when available.                                                                                                                                                                 |
| Checkpoint max age                           | How long unused resume checkpoints remain before cleanup. Active queued transfers are retained.                                                                                                                                              |
| Pre-signed URL expiration                    | How long a generated share URL remains valid.                                                                                                                                                                                                |
| Density                                      | `Comfortable` leaves room around each row; `Compact` fits more rows on screen. Applies at once; Cancel reverts it.                                                                                                                           |
| Size units                                   | `Binary, KB labels` divides by 1024; `Decimal` divides by 1000; `Binary (KiB)` divides by 1024 and labels KiB and MiB. Applies at once to the object list and info panels.                                                                   |
| Date format                                  | `Locale format` uses your system's date style; `ISO 8601` shows local `YYYY-MM-DD HH:mm`; `Relative` shows times such as `3 min ago` and uses the locale format after seven days. Applies at once.                                           |
| Reset all settings                           | Returns every setting to its starting value and restarts the app. A factory reset also deletes saved connections and encryption.                                                                                                             |
| Forgot password                              | On the Unlock prompt. A lost password cannot be recovered, so this erases the encrypted vault and its saved connections, then restarts the app.                                                                                              |
| Save and Cancel                              | Save applies the Transfers, Updates, Sharing and Appearance settings. Save shows while one of them is on screen or has unsaved changes. Security and saved-connection changes apply at once.                                                 |

Transfer status exposes progress, speed, ETA, retry phase, and checkpoint state in the Transfers panel. Checkpoints never override an object-generation mismatch.
