# Settings Glossary

| Setting                                      | Meaning                                                                                                                                                                                                                                                                                       |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Update channel                               | `Stable` follows published releases. `Beta` follows pre-release builds and also includes newer stable releases.                                                                                                                                                                               |
| Automatically check for and download updates | Checks for new versions in the background and downloads them. Installing still needs your confirmation.                                                                                                                                                                                       |
| Performance preset                           | `Safe` uses less memory and runs slower; `Balanced` is the default; `Max` gives the highest throughput using more memory and CPU. `Custom` appears, but cannot be chosen, once an Advanced value no longer matches the preset; choosing `Safe`, `Balanced` or `Max` applies its values again. |
| Bandwidth cap                                | Maximum total network speed used for transfers. `Unlimited` uses all available bandwidth.                                                                                                                                                                                                     |
| Desktop notifications                        | OS notifications for finished transfers and updates. Off stops them; in-app toasts still appear, and the operating system can also block them.                                                                                                                                                |
| Retry base delay                             | Initial wait before the first retry. Each later retry waits longer using exponential backoff.                                                                                                                                                                                                 |
| Parallel download threshold                  | Files larger than this use parallel range-GET downloads; smaller files use one request.                                                                                                                                                                                                       |
| Download part size                           | Size of each range-GET chunk for parallel downloads. Larger parts use fewer requests and more memory.                                                                                                                                                                                         |
| Download part concurrency                    | How many parts of a single file are downloaded in parallel.                                                                                                                                                                                                                                   |
| Upload part size                             | Size of each multipart upload chunk. Larger parts use fewer requests and more memory.                                                                                                                                                                                                         |
| Upload part concurrency                      | How many parts of a single file are uploaded in parallel.                                                                                                                                                                                                                                     |
| Enable resumable large downloads             | Saves progress for large multipart downloads so an interrupted transfer can resume from where it stopped.                                                                                                                                                                                     |
| Verify transfer checksums when available     | Compares a server-provided integrity checksum after each transfer. Adds slight CPU cost.                                                                                                                                                                                                      |
| Checkpoint retention                         | How long resume checkpoints stay on disk before cleanup. Active queued transfers are retained.                                                                                                                                                                                                |
| Pre-signed URL expiration                    | How long generated share links stay valid before expiring.                                                                                                                                                                                                                                    |
| Density                                      | `Comfortable` leaves room around each row; `Compact` fits more rows on screen. Applies at once; Cancel reverts it.                                                                                                                                                                            |
| Size units                                   | `Binary, KB labels` divides by 1024; `Decimal` divides by 1000; `Binary (KiB)` divides by 1024 and labels KiB and MiB. Applies at once to the object list and info panels.                                                                                                                    |
| Date format                                  | `Locale format` uses your system's date style; `ISO 8601` shows local `YYYY-MM-DD HH:mm`; `Relative` shows times such as `3 min ago` and uses the locale format after seven days. Applies at once.                                                                                            |
| Reset all settings                           | Returns every setting to its starting value and restarts the app. A factory reset also deletes saved connections and encryption.                                                                                                                                                              |
| Forgot password                              | On the lock view. A lost password cannot be recovered, so this erases the encrypted vault and its saved connections, then restarts the app.                                                                                                                                                   |
| Save and Cancel                              | Save applies the Transfers, Updates, Sharing and Appearance settings. Save shows while one of them is on screen or has unsaved changes. Security and saved-connection changes apply at once.                                                                                                  |

Transfer status exposes progress, speed, ETA, retry phase, and checkpoint state in the Transfers panel. Checkpoints never override an object-generation mismatch.
