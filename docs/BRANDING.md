# Branding

## Name

Use `S3 Sidekick` in prose and `S3-Sidekick` in repository, package, and download names. Do not use the retired `IYERIS` name.

## Logo and icons

Use the repository icon assets for product identity. Keep the supplied aspect ratio and transparent padding. Use the existing Lucide icon set for interface actions; do not redraw action icons as text glyphs.

## UI language

Use short, direct action labels such as `Connect`, `Upload`, `Download`, `Save`, and `Cancel`. Keep destructive actions explicit and pair public-access or credential actions with a visible confirmation.
